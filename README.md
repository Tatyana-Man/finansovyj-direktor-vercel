| Приём референса | Как применили у нас |
|---|---|
| BLUF: первый абзац — цифры (77 ЖК, 9 503 кв., от 10,5 млн, медиана) | На каждой странице первым абзацем идут число программ, число школ, вход, медиана и срок. Цифры считаются из базы автоматически |

## Структура (25 URL из 1 базы)
- `/` — главная: BLUF, карта цен, распределение по ценовым диапазонам, карточки с фильтрами (тип/бюджет/формат), сортируемая таблица, хабы.
- **Интенты из Wordstat:** `/perepodgotovka/`, `/povyshenie-kvalifikacii/`, `/besplatnye/`, `/otzyvy/` (рейтинг школ + фильтры по школе, типу и оценке). Интент «цены» закрывает главная: карта цен, диапазоны и таблица.
- **Срезы по критериям:** `/mba/`, `/msfo/`, `/s-nulya/`, `/dlya-opytnyh/`, `/do-50000/`, `/rassrochka/`, `/s-diplomom/`.
- `/kurs/<id>/` — страница курса (Course + AggregateRating).
- `sitemap.xml`.

## Данные (реальные, проверено 09.10.2026)
- **Курсы** — 26 программ от 19 школ. Взяты из проекта «Сервис подбора курсов из фидов» (фиды AdvCake и EDPartners + sitemap школ, поиск по «финансовый директор / CFO»). Срок, часы, документ, формат и рассрочка — со страниц курсов. Если школа чего-то не указала, в поле стоит «—».
  Исключены: netology «Стандартный» (страница отдаёт 404) и mosdigitals.ru (страница отрисовывается скриптом, данных нет).
- **Отзывы** — provereno.pro/schools/<школа>/testimonials/, первоисточник otzovik.com и Яндекс. В `data/provereno_reviews.json` лежат все 2 281 отзыв, на сайт попадают отзывы с упоминанием финансов плюс 6 последних по каждой школе. Отзывы о школе в целом, а не о конкретном курсе.
- Бесплатных курсов финдиректора в источниках нет, поэтому страницы «бесплатные» нет.

## Обновление
```bash
python3 data/make_data.py   # пересобрать базу из RAW-списка и отзывов
python3 build.py            # пересобрать сайт
```
Чтобы посмотреть сайт, откройте `site/index.html` двойным кликом: все ссылки относительные.

## Публикация (Vercel)
1. Домен задан в `build.py` → `SITE_URL = "https://finansovyj-direktor.vercel.app"`.
2. `zsh publish.sh` — бэкап, сборка `site/` и `deploy/`, выкладка `deploy/` через Vercel CLI (`vercel deploy --prod`).
   Один раз перед первой публикацией: `npm i -g vercel`, затем `vercel login` и `cd deploy && vercel link`.
3. Счётчик и подтверждение прав в Яндекс Вебмастере / Google Search Console — константы `METRIKA`, `YANDEX_VERIFICATION`,
   `GOOGLE_VERIFICATION` в начале `build.py` (сейчас пустые).
4. После выкладки отправьте `https://finansovyj-direktor.vercel.app/sitemap.xml` в оба вебмастера.

При каждой сборке выводится проверка мета-тегов: уникальность title/description, title ≤ 70 и description 70–170 символов.
