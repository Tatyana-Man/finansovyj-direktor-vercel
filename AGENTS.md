# AGENTS.md — инструкции для Codex (и других ИИ-агентов)

Проект: статический SEO-сайт «CFO Навигатор — обучение финансовых директоров» (https://finansovyj-direktor.vercel.app).
Это уникализированная копия сайта finansovyj-direktor.ru: свой дизайн, тексты, мета и статьи; курсы и логика общие — агрегатор курсов
для финансовых директоров (подборки, страницы курсов, отзывы, статьи, квиз, сравнение).
Владелец — не программист, работает на Mac. **Отвечать по-русски, простым языком, без жаргона.**

## Главные правила
1. **Не выдумывать данные.** Цены, сроки, часы, документы, лицензии, модули, преподаватели, отзывы —
   только с реальных страниц школ и из источников проекта. Нет данных — поле пустое / «—» / «не указано».
2. **Приоритет школ** — `data/priorities.json` (порядок в списке = приоритет). Приоритетные школы
   показываются первыми везде: каталог, лесенка цен (сортировка «по умолчанию»), квиз (бонус к баллам).
3. **Реферальные ссылки** — только через `data/make_reflinks.py` (см. ниже). Ссылки на сайты школ:
   `rel="nofollow noopener"`, **без** `sponsored`. Маркировку рекламы не добавлять (сайт информационный).
4. **FAQ:** в 3–4 из 5–7 вопросов явно называть тему («финансовый директор», «финдиректор», «CFO»).
5. **Мобильная версия:** никакой горизонтальной прокрутки на ширине 375 px; шрифт не меньше 12 px;
   зоны нажатия ≥ 36 px.
6. **Не добавлять без запроса:** реквизиты. Счётчик аналитики и мета-теги вебмастеров — только те, что пришлёт владелец
   (`METRIKA`, `YANDEX_VERIFICATION`, `GOOGLE_VERIFICATION` в начале `build.py`). Тексты не копировать с finansovyj-direktor.ru.
   Политики конфиденциальности и соглашения нет — на сайте нет форм; при добавлении форм или метрики вернуть их.
7. **Футер** — без повторов слова «курсы» и дублирующих ссылок.
8. Названия школ — как в `priorities.json` / данных; склонять конструкцией «в школе «…»».
9. Документы об обучении называть точно: «диплом о профессиональной переподготовке»,
   «удостоверение о повышении квалификации», «сертификат школы». Не писать «установленного образца».

  и на хостинге в `backups/finansovyj-direktor`, хранятся 30 последних). Копия также делается ежедневно в 20:00

- Публикация — только `zsh publish.sh`: он отменяется, если в проекте нет файлов или в сборке < 50 страниц.
- Восстановление: распаковать последний архив из `~/Documents/Бэкапы финдир` (или скачать с хостинга).

## Структура
- `build.py` — генератор сайта. Тексты подборок — `data/landing_texts.py`, статьи — `data/articles.py`,
  программы по модулям и лицензии — `data/course_program.py`, статьи — `data/zhurnal/<slug>.py`.
- `data/courses.json` — база курсов (собирается `data/make_data.py`), `data/promo_codes.json` — промокоды,
  `data/keywords.json` — закреплённые keyword реф-ссылок (не редактировать вручную),
  `data/provereno_reviews.json` — отзывы, `data/coverage.json` — покрытие тем программ.
- `assets/style.css`, `assets/app.js` (квиз, лесенка, сравнение, фильтры, меню), `assets/fonts/` — свои шрифты.
- `site/` — версия для просмотра двойным кликом; `deploy/` — боевая версия (чистые URL). Обе генерируются,
  **руками не править**.

## Команды
```bash
python3 data/make_data.py                                              # пересобрать базу курсов
/Users/tatyana/Downloads/ref-link-service/venv/bin/python data/make_reflinks.py   # реф-ссылки
```

После любых правок всегда пересобирать **обе** версии (`build.py` и `build.py --prod`).
Сборка печатает проверку мета-тегов (уникальность, title ≤ 70, description 70–170) — ошибок быть не должно.

## Реферальные ссылки
- sub1 = `vercel2`; keyword основного каталога `fin-dir`, блока «Финансовый менеджмент» — `fin-dir-dop`.
- Если у школы несколько курсов — к keyword добавляется номер (1, 2, 3…) отдельно по каждой школе.
- Выданные keyword закреплены в `data/keywords.json`; новым курсам — следующий свободный номер школы,
  номера удалённых курсов не переиспользуются.
- Логику сетей в `/Users/tatyana/Downloads/ref-link-service` не менять.

## SEO
- JSON-LD: WebSite, Organization, CollectionPage, ItemList, Course (без `sameAs`), FAQPage,
  BreadcrumbList, Article. Уникальные title/description на каждой странице.
- Подборки лежат в корне (`/perepodgotovka/`, `/mba/`…), без `/napravleniya/`.
- Статьи — `/stati/<slug>/`: одна статья = один интент; подзаголовки, списки, обложка, адаптивная HTML-инфографика.
- Хостинг — Vercel: `build.py --prod` кладёт в `deploy/` файл `vercel.json` (чистые адреса со слешем).

1. Пересобрать обе версии, убедиться, что мета-проверка без ошибок.
2. Открыть `site/index.html` и изменённые страницы; проверить ширину 375 px (scrollWidth ≤ 375).
3. Кратко отчитаться по-русски: что сделано, что не сделано и почему (особенно если не хватило данных).
